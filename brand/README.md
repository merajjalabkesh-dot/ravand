# نشانهٔ برند «روند» — Ravand Mark

## ایدهٔ نشانه

سه خانه که مثل پله از پایین‌چپ به بالاراست بالا رفته‌اند، هرکدام پررنگ‌تر از قبلی.

این فرم از روی یک چیز واقعی در خود اپ برداشته شده: هیت‌مپ روزانه در صفحهٔ گزارش‌ها. آنجا خانه‌های تقویم جلالی بر اساس شدت انجام‌دادن عادت‌ها پر می‌شوند — خالی، کم‌رنگ، پر، و کهربایی برای روزهای کامل. نشانه همان زبان بصری را در سه پله خلاصه می‌کند.

هیچ حرفی در نشانه نیست. «ن» — که نسخهٔ قبلی روی آن بود — هیچ چیزی از روز و زمان و پیشرفت را رمزگذاری نمی‌کرد و اگر اسم اپ را عوض می‌کردی، همان لوگو روی هر محصول دیگری هم کار می‌کرد. این نشانه فقط برای «روند» معنا دارد.

## ساختار

سه خانهٔ ۸۸×۸۸ پیکسل با گوشهٔ گرد ۲۰، روی قطری از پایین‌چپ به بالاراست:

| خانه | مختصات | شفافیت |
|---|---|---|
| اول (پایین) | `116,292` | ۰٫۳۲ |
| دوم (وسط) | `212,212` | ۰٫۶۲ |
| سوم (بالا) | `308,132` | ۱٫۰ |

همه یک رنگ دارند (`#8b5cf6`) و فقط شفافیتشان فرق می‌کند. همین یک‌رنگی باعث می‌شود نشانه در ۱۶ پیکسل هم بخواند؛ چهار سطح رنگی جدا (سبز، بنفش، کهربایی) در آن سایز محو می‌شدند.

## نسخه‌ها

| فایل | کاربرد |
|---|---|
| `ravand-mark.svg` | فایل اصلی. `currentColor` است، با `color` در CSS رنگ می‌گیرد |
| `ravand-mark-dark.svg` | روی زمینهٔ `#0a0f1f` |
| `ravand-mark-light.svg` | روی سفید، با بنفش تیره‌تر `#6d28d9` برای کنتراست |
| `ravand-mark-gradient.svg` | گرادیان `#8b5cf6` -> `#43e8a8`. فقط هیرو و صفحهٔ دانلود |
| `ravand-mark-mono.svg` | سیاه مطلق، برای چاپ |
| `ravand-mark-maskable.svg` | داخل دایرهٔ امن ۸۰٪، برای آیکون اندروید و ویندوز |

آیکون‌های رندرشده: `icon-16`، `icon-32`، `icon-180` (iOS)، `icon-192`، `icon-512`، `icon-512-maskable`.

## نکتهٔ مهم دربارهٔ سایزهای کوچک

آیکون‌های رندرشده عمداً با ابعاد بزرگ‌تر و شفافیت بالاتر (۰٫۵۵ به‌جای ۰٫۳۲) ساخته شده‌اند، نه با همان اعداد نسخهٔ اصلی. دلیلش این است که در ۱۶ و ۳۲ پیکسل، پلهٔ اول با شفافیت ۰٫۳۲ عملاً ناپدید می‌شود و نشانه به دو نقطهٔ نامنظم تبدیل می‌شود. اگر روزی خواستی همه را یکسان کنی، بدان که در آن حالت شکل در آیکون‌های کوچک از بین می‌رود.

حداقل اندازهٔ قابل‌قبول: ۱۶ پیکسل، ولی در همان اندازه فقط «سه نقطهٔ صعودی» دیده می‌شود و جزئیات هر پله محو است. زیر ۲۴ پیکسل باید انتظار خوانایی کامل نداشته باشی.

## استفاده

```jsx
<span className="brand-mark" style={{ color: '#8b5cf6' }} />
```

```css
.brand-mark { display: inline-block; width: 32px; height: 32px; }
.brand-mark svg { width: 100%; height: 100%; }
```

هیچ فیلتر و گرادیانی داخل فایل‌ها نیست. هاله را در CSS اضافه کن، نه در خود SVG — وگرنه در آیکون‌های کوچک لبه‌ها محو می‌شود.

## اگر خواستی نشانه را تغییر بدهی

سه چیز را با هم تغییر بده: ابعاد خانه، گپ بین خانه‌ها، و گوشهٔ گرد. نسبت‌های فعلی: خانه ۸۸، گپ ۸ (مرکز به مرکز ۹۶)، گوشه ۲۰.

گپ را زیر ۶ نبر — سه خانه یک توده می‌شوند. گوشه را خیلی کم نکن — حس «چیپ» می‌رود و به هدردی اپ گم می‌شود.
